# Functional beat taxonomy

Label a beat by the change it creates in the viewer—not by its grammar.

## Beat functions

| Function | Job | Decision test |
|---|---|---|
| `pattern-break` | Interrupt the expected frame | Would the opening still arrest attention without this line? |
| `promise` | Define the outcome or value ahead | Does it tell viewers what they will gain? |
| `context` | Supply essential setup | Would later beats be confusing without it? |
| `problem` | Make friction or cost concrete | Does it establish what is wrong or at stake? |
| `proof` | Increase belief with evidence | Does it provide a result, demonstration, source, or credible example? |
| `mechanism` | Explain why something happens | Does it reveal the causal model? |
| `contrast` | Clarify through difference | Does it sharpen the point by opposing two states or choices? |
| `open-loop` | Create a specific unanswered question | Can the viewer clearly name what remains unresolved? |
| `step` | Advance an actionable sequence | Is it one distinct part of a process or list? |
| `reveal` | Deliver withheld or reframed information | Does it close a meaningful gap? |
| `application` | Translate insight into use | Does it show what the viewer should do with the idea? |
| `recap` | Compress the argument | Does it make the accumulated logic easier to retain? |
| `bridge` | Connect two necessary sections | Does it explain why the next subject follows? |
| `cta` | Direct the next action | Does it ask for one clear behavior after the payoff? |

Use the smallest number of labels that explain the sequence. Do not force every sentence into a separate beat.

## Retention drivers

A video may combine several:

| Driver | What creates momentum | Failure mode |
|---|---|---|
| `question-pressure` | A precise unresolved question | Vague teasing with no meaningful answer |
| `value-ladder` | Each beat adds practical value | Repetition disguised as depth |
| `stakes-rise` | Consequences or opportunity become clearer | Manufactured drama unsupported by facts |
| `proof-chain` | Evidence accumulates toward belief | Examples that do not prove the claim |
| `pace-renewal` | Form, sentence length, or visual rhythm changes | Random interruption without purpose |

## Audience-state analysis

For each beat, complete:

```text
Before: the viewer believes, knows, expects, or asks…
Beat job: this passage changes that by…
After: the viewer now believes, knows, expects, or asks…
Handoff: therefore the next necessary beat must…
```

If the before and after states are indistinguishable, the beat may be redundant.

## Structure-transfer rule

Transfer the abstract progression:

```text
viewer state A → functional job → viewer state B
```

Do not transfer the original creator’s phrase, claim, example, anecdote, or persona.
